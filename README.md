# DTRV — Daily Time Record (CS Form 48)

A small web app for recording employee time in/out with a PIN and printing the monthly Civil Service Form No. 48 on A4.

- **Plan & features:** [`docs/01-PLAN.md`](docs/01-PLAN.md)
- **Technical specification:** [`docs/02-TECHNICAL.md`](docs/02-TECHNICAL.md)
- **UI: B + C variations (pick one):** [`mockup/ui-bc-variations.html`](mockup/ui-bc-variations.html) · earlier options: [`mockup/ui-options.html`](mockup/ui-options.html)
- **Working prototype:** open [`mockup/index.html`](mockup/index.html) in Chrome. Demo codes `024` (fixed) and `205` (flexi), admin PIN `123456`.

Stack: Vercel (static + 2 functions) + Dexie Cloud (synced IndexedDB).

Status: design phase. No application code yet.
